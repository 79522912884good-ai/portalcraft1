# Portal Craft (Fabric, Minecraft 1.21.11)

Мод по образцу CS 1.6 Craft, но про Portal. Из Portal в мод **ничего не вложено**: звуки и текстуры читаются
во время игры из вашей Steam-установки (`steamapps/common/Portal`), как это делал оригинал с Counter-Strike.

## Что умеет сейчас
- **F6** переключает интерфейс Portal ↔ Minecraft (состояние запоминается, при переключении играются
  `wpn_hudon.wav` / `wpn_hudoff.wav` из игры).
- В режиме Portal: **ЛКМ** — синий портал, **ПКМ** — оранжевый, **R** — закрыть оба. Ломать блоки и бить мобов
  в этом режиме нельзя, как и в CS-моде перехватываются клавиши.
- Порталы: вход в один выводит из другого с сохранением скорости и поворотом взгляда (стены, пол, потолок).
  Ставятся на любой цельный блок, кроме бедрока. Рисуются частицами (синее и оранжевое кольцо).
- HUD Portal: прицел с двумя дугами (синяя слева, оранжевая справа, ярче когда портал открыт) и здоровье
  в стиле HL2 (шкала 100, жёлтый цвет HUD, красный при ≤25). Ванильный HUD скрыт, пока режим Portal включён.
- Звуки из игры: выстрел синим/оранжевым, неверная поверхность, закрытие, вход/выход из портала.
- Поиск игры: настройка `portal_dir`, реестр Steam, стандартные пути, `libraryfolders.vdf` (другие диски).

## Сборка
Нужны JDK 21 и интернет.
1. Откройте https://fabricmc.net/develop , выберите 1.21.11 и сверьте значения в `gradle.properties`
   (`yarn_mappings`, `loader_version`, `loom_version`) — я не мог их проверить без сети.
2. `gradle wrapper` (один раз), затем `./gradlew build`.
3. Готовый мод: `build/libs/portalcraft-1.0.0.jar`. Положите его в `mods/` вместе с Fabric API 0.141.6+1.21.11.

## Настройка
Файл `config/portalcraft.properties`:
- `portal_dir` — путь к папке Portal, если автопоиск не нашёл (там, где лежат `portal/` и `hl2/`).
- `enabled` — запоминается режим F6.
- `crosshair_blue`, `crosshair_orange` — необязательно: пути VTF внутри VPK (например
  `materials/vgui/hud/xxx.vtf`). Тогда прицел рисуется из текстур игры, а не примитивами.

При первом запуске мод создаёт `portalcraft-assets.txt` в папке игры: список HUD-файлов, звуков портальной
пушки и шрифтов, найденных в ваших VPK. По нему можно подобрать точные пути.

## Статус проверки (честно)
- **Проверено** (компиляция и тесты на синтетических файлах по спецификации формата): `Vpk` (v2, встроенные
  данные, preload, внешние `_NNN.vpk`), `Vtf` (DXT1/DXT3/DXT5/BGRA/RGBA/RGB…), `PortalFinder`, `PortalAssets`.
- **Не проверено**: всё, что использует API Minecraft (`PortalServer`, `PortalClient`, `PortalNet`, `Compat`).
  В среде, где я писал код, не было Minecraft/Fabric и интернета, поэтому он не компилировался и не запускался.
  Самые вероятные места ошибок при сборке на 1.21.11 вынесены в **`Compat.java`** (мир игрока, позиция,
  категория клавиш, телепорт, регистрация текстуры, `drawTexture`). Остальное — стандартный Fabric API.
- Не тестировались на реальных файлах Portal: пути звуков заданы по памяти с запасным поиском по подстроке.

## Чего ещё нет по сравнению с CS-модом
- 3D-модель портальной пушки в руках (`v_portalgun.mdl` — формат Source MDL/VVD/VTX, нужен отдельный парсер
  и рендер).
- Настоящие «окна» порталов (вид сквозь портал) — сейчас кольцо из частиц.
- Шрифт HL2 из игры, текстурные блоки Portal, турели, кубы, лазеры.
